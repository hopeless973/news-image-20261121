A 1024x1024 PNG summing up the world's news of Saturday 21 November 2026 in one image: COP31 in overtime as the lead story, plus 11 more verified stories from every region, each with a region tag and a colour-coded category. `main.py` copies `entry.png` to `/output/entry.png` byte for byte. The image was drawn with Pillow by `build_image.py` using the bundled DejaVu fonts (free licence, see the font files in `fonts/`).

## Run it

```sh
python3 main.py
```
